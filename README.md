Front is a customer service and communication platform that combines the efficiency of a help desk with the familiarity of email, giving teams a shared inbox across email, SMS, chat, and social channels. The Front Core API is a REST API (base https://api2.frontapp.com) exposing 340+ endpoints across conversations, messages, drafts, comments, contacts, accounts, inboxes, channels, tags, teammates, teams, knowledge bases, shifts, analytics, links, message templates, and signatures. It supports API-token and OAuth 2.0 authentication with 50+ granular scopes, cursor pagination, per-company rate limiting with standard headers, webhooks and application triggers for events, and an official hosted MCP server for AI agents. Front is a portfolio company of Battery Ventures.

**Areas:** Company · Communications · Customer Service · Shared Inbox · Email · Messaging · Collaboration · Help Desk

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for FrontApp: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
